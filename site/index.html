What's in the box

What links here
Every page lists the pages that point to it, so nothing ends up orphaned.
Edits never collide
If someone saves while you're still typing, your save is held back instead of wiping out theirs, and your text stays in the editor.
Markdown you already know
GitHub-style tables, task lists and code blocks. Put [TOC] on its own line for a table of contents.
Safe with any editor
Raw HTML is escaped and javascript: links are dropped, so a page can never run scripts in a reader's browser.
Your logins, your rules
Anyone signed in can edit by default. One gate narrows it to admins, a team, or whoever you like.
Titles in any language
Café crème lives at /wiki/café-crème, 日本語 at /wiki/日本語. Renaming a page never breaks its address.
Looks like your app
Plain Blade views, styled with CSS variables. Publish them and swap in your own layout.
Scriptable
Create pages from code, read the history, and listen for a PageSaved event to notify, index or cache.

Running in under a minute

Laravel 12 or 13 on PHP 8.3 or newer, with any database Laravel supports.

  1. Install the package 
    composer require ruvelo/laravel-wiki
  2. Create its tables 
    php artisan migrate
  3. Open /wiki

    Sign in and write the first page. That's it.

  4. Decide who can edit (optional) 
    Gate::define('wiki-edit', fn ($user) => $user->is_admin);
